💡 คำแนะนำ: เมื่อกรอกหรือวางรายชื่อเสร็จแล้วและกดบันทึก ข้อมูลจะถูกเก็บไว้ในหน่วยความจำของเครื่องนี้ทันที คุณครูไม่ต้องแก้ไขไฟล์โค้ด HTML ใดๆ เลยครับ

📚 การเปลี่ยนชื่อวิชาเรียน: คุณครูสามารถเปิดไฟล์ index.html ด้วย Notepad และค้นหาแท็ก <select id="subject-select"> จากนั้นแก้ไขหรือเพิ่มชื่อวิชาภายในแท็ก <option> ได้ตามต้องการเลยครับ!

เมื่อใส่ Web App URL แล้ว ทุกครั้งที่นักเรียนกดลงทะเบียน ระบบจะส่งค่า (ระดับชั้น, ชื่อ-สกุล, วิชาที่เรียน, เครื่องที่ใช้งาน, วัน-เวลา) ไปบันทึกยัง Google Sheet ทันที

วิธีเชื่อมต่อกับ Google Sheet

  1. สร้าง Google Sheet ใหม่ และตั้งหัวตารางในแถวแรก 5 คอลัมน์: วัน-เวลา, ระดับชั้น, ชื่อ-สกุล, วิชาที่เรียน, เครื่องที่ใช้งาน
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดด้านล่างนี้ไปวาง: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp,
    data.grade,
    data.studentName,
    data.subject,
    data.computer
  ]);
  return ContentService.createTextOutput("Success");
}
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การใช้งานเว็บใหม่ (New deployment)
  5. ตั้งค่าดังนี้:
    • เลือกประเภท: เว็บแอป (Web app)
    • ผู้มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)
  6. กด Deploy คัดลอก URL ที่ได้มาวางในช่องรับลิงก์ด้านบนนี้

ลงทะเบียนเข้าใช้งานสำเร็จ!
